    Questions judges will ask

    Pitch honestly: school names and locations are real, but enrollment figures are placeholders, asthma numbers are a population-level estimate, and the prototype AQI is based on hourly PM2.5 only. Verify today’s CAQM/GRAP order before describing closure rules.

    How it works (simple roadmap)

    Now: browser dashboard + live forecast. Next: verify station data and add real school enrolment. Later: alerts only after a school pilot and consent process.

    1. 1 · Air dataOpen-Meteo CAMS forecast; OpenAQ measurements are optional. NASA FIRMS fire data is a future addition.
    2. 2 · Match schoolsOptional AWS Lambda finds nearby OpenAQ stations. API key stays server-side.
    3. 3 · Prepare resultAPI Gateway serves station readings; page estimates a PM2.5-based AQI and action band.
    4. 4 · School planThis static HTML, CSS and JavaScript page shows school-level trends, actions and a parent-message draft.
    5. 5 · Pilot carefullyAmplify can host it. Test accuracy and school workflows before considering real SMS.

    Read this dashboard: the large number shows schools above the prototype indoor-action threshold. Select a school for its hourly chart and checklist.
